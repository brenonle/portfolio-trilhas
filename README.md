# 💻 Portfólio Pessoal — Programa Trilhas

Portfólio pessoal desenvolvido para apresentar minha trajetória na tecnologia, experiências profissionais e projetos de desenvolvimento web.

---

## 📖 Sobre o projeto

Este portfólio foi criado como parte do **Programa Trilhas — Desenvolvimento Front-end**, com o objetivo de aplicar conhecimentos em HTML, CSS e boas práticas de desenvolvimento web.

O projeto reúne informações sobre minha formação, experiências e trabalhos desenvolvidos, proporcionando uma apresentação organizada e acessível.

---

## ✨ Páginas e Funcionalidades

- **Página Inicial (`index.html`):** Apresenta minha foto de perfil, nome, descrição principal, links para redes sociais e botões de navegação rápida.
- **Sobre mim (`sobre.html`):** Mantém o perfil no topo e apresenta um resumo sobre minha trajetória acadêmica, interesses na área de tecnologia e objetivos profissionais.
- **Meus Projetos (`projetos.html`):** Galeria em formato de cards exibindo os projetos desenvolvidos ao longo do programa (como os desafios de Lógica de Programação), com imagem prévia e link direto para o repositório no GitHub.
- **Meus Certificados:** Botão de acesso direto para a pasta no Google Drive com os certificados conquistados.
- **Background em Vídeo:** Fundo dinâmico em vídeo (`.mp4`) com camada escura suave (*overlay*) para destacar o conteúdo central.

---

## 🚀 Tecnologias utilizadas

- **HTML5:** Estruturação semântica das páginas (`index.html`, `sobre.html` e `projetos.html`).
- **CSS3:** Estilização moderna, layout responsivo com *Flexbox* e *CSS Grid*, efeito translúcido (*Glassmorphism*) e posicionamento de vídeo de fundo.
